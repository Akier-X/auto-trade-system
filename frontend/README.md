# 自動売買システム Webダッシュボード

React + TypeScript + Tailwind CSSで構築されたリアルタイムトレーディングダッシュボード。

## 機能

- **ダッシュボード**: ライブ市場フィード、マルチLLMコンセンサス
- **戦略**: 短期トレード・成長投資の設定
- **メモリバンク**: インテリジェンス履歴、ベクトル検索
- **設定**: システム・API設定管理

## セットアップ

```bash
# 依存パッケージインストール
npm install

# 開発サーバー起動
npm run dev

# ビルド
npm run build
```

## 技術スタック

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router v6
- Zustand (状態管理)
