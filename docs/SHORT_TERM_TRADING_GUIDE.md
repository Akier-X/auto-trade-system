# Short-Term Trading System Guide

## 概要

短期トレードシステムは、デイトレードとスイングトレードに特化した自動売買システムです。テクニカル分析、モメンタム、短期センチメントを活用し、数時間から5日間の保有期間で利益を追求します。

## システムの特徴

### 短期トレード vs 成長投資

| 項目 | 短期トレード | 成長投資 |
|------|-------------|----------|
| 保有期間 | 数時間〜5日 | 数週間〜数ヶ月 |
| 分析手法 | テクニカル分析中心 | ファンダメンタル分析中心 |
| リスク管理 | 厳格(2%ストップロス) | 緩やか(5-10%ストップロス) |
| ポジションサイズ | 5-10% | 10-20% |
| 利益目標 | 3%+ | 10%+ |
| 売買頻度 | 高頻度 | 低頻度 |

### 主な機能

1. **テクニカル指標分析**
   - RSI (相対力指数)
   - MACD (移動平均収束拡散法)
   - ボリンジャーバンド
   - 移動平均線 (SMA/EMA)
   - ストキャスティクス
   - ATR (平均真実範囲)
   - 出来高分析

2. **シグナル生成**
   - 複数指標の統合分析
   - モメンタム評価
   - 短期センチメント分析
   - 信頼度スコアリング

3. **リスク管理**
   - 1トレードあたり最大2%損失
   - 1日あたり最大5%損失
   - 最大ドローダウン10%
   - 最大ポジションサイズ10%
   - 最大保有時間120時間(5日)

4. **エグジット管理**
   - 利益確定: 3%以上の利益
   - ストップロス: 2%の損失
   - 時間ベース: 5日間保有後自動決済
   - テクニカル反転シグナル

## セットアップ

### 1. データベーステーブル作成

```bash
python scripts/setup_short_term_tables.py
```

作成されるテーブル:
- `price_history` - OHLCV価格データ
- `trade_metadata` - 戦略別トレードメタデータ
- `strategy_performance` - 戦略パフォーマンス
- `intraday_signals` - 短期シグナル履歴
- `market_conditions` - 市場状態

### 2. 価格データ取得

```bash
# すべての監視銘柄の過去90日分データ取得
python scripts/fetch_price_data.py --days 90

# 特定銘柄のデータ取得
python scripts/fetch_price_data.py --ticker 7203 --days 90
```

### 3. 環境変数設定

`.env`ファイルに以下を追加:

```env
# 短期トレード設定
SHORT_TERM_ALLOCATION=0.3           # 資本の30%を短期トレードに配分
SHORT_TERM_MAX_POSITIONS=5          # 最大同時ポジション数
SHORT_TERM_PROFIT_TARGET=3.0        # 利益目標 (%)
SHORT_TERM_STOP_LOSS=2.0            # ストップロス (%)
SHORT_TERM_MAX_HOLDING_HOURS=120    # 最大保有時間 (時間)
```

## 戦略ロジック

### エントリー条件

以下の条件を満たした場合にエントリー:

1. **テクニカルスコア ≥ 65点**
   - RSI: 買われ過ぎ/売られ過ぎゾーン
   - MACD: ゴールデンクロス/デッドクロス
   - ボリンジャーバンド: バンド境界付近
   - トレンド: 上昇/下降トレンド

2. **モメンタム確認**
   - 5日間の価格モメンタム
   - 出来高モメンタム

3. **センチメント確認**
   - 過去48時間のAI分析結果
   - 強気/弱気のコンセンサス

4. **リスク管理**
   - 日次損失限度未達
   - ポジション数上限未達
   - ドローダウン限度未達

### エグジット条件

以下のいずれかを満たした場合にエグジット:

1. **利益確定**: 3%以上の利益
2. **ストップロス**: 2%の損失
3. **時間制限**: 120時間(5日)保有
4. **テクニカル反転**: 売りシグナル発生
5. **RSI過熱**: RSI > 75 (買いポジション)

## テクニカル指標詳細

### RSI (相対力指数)
- 期間: 14日
- 買われ過ぎ: > 70
- 売られ過ぎ: < 30
- 用途: 過熱感の判定

### MACD
- Fast EMA: 12日
- Slow EMA: 26日
- Signal: 9日
- 用途: トレンド転換の検出

### ボリンジャーバンド
- 期間: 20日
- 標準偏差: 2σ
- 用途: ボラティリティとエントリーポイント

### 移動平均線
- 短期: 5日、10日
- 中期: 20日
- 長期: 50日
- 用途: トレンド方向の判定

## パフォーマンス指標

システムは以下の指標を追跡:

- **勝率**: 勝ちトレード数 / 総トレード数
- **平均リターン**: 平均損益率
- **平均保有時間**: トレードあたりの平均保有時間
- **シャープレシオ**: リスク調整後リターン
- **最大ドローダウン**: ピークからの最大下落率
- **プロフィットファクター**: 総利益 / 総損失

## リスク管理

### ポジションサイジング
```
ポジションサイズ = 利用可能資本 × (5% + 信頼度 × 5%)
```

- 最小: 5% (低信頼度)
- 最大: 10% (高信頼度)

### ストップロス計算
```
ストップロス価格 = エントリー価格 × (1 - 0.02)
```

### 日次損失限度
- 利用可能資本の5%に達したら取引停止

## トラブルシューティング

### 価格データが取得できない

```bash
# yfinanceが正しくインストールされているか確認
pip install yfinance

# 手動で価格データ取得
python scripts/fetch_price_data.py --ticker 7203 --days 30
```

### シグナルが生成されない

1. 価格データの確認:
   ```sql
   SELECT COUNT(*) FROM price_history WHERE ticker_code = '7203';
   ```

2. 監視銘柄の確認:
   ```sql
   SELECT * FROM monitored_tickers WHERE is_active = TRUE;
   ```

3. ログの確認:
   ```bash
   tail -f logs/short_term_system.log
   ```

### ポジションが決済されない

1. エグジット条件の確認
2. リスク管理の状態確認
3. ブローカーAPI接続確認
